# 🔑 Gemini API Key Requirement

### ⚠️ Important

NeuroPrep AI uses the **Google Gemini API** for its AI-powered
features.

Because this version of the project is deployed as a static website,
users who want to use the AI features need to provide **their own
Gemini API key** through the application's API key option.

### If you only want to view the website

No API key is required just to open and explore the website.

### If you want to use AI features

You will need:

1. A Google Gemini API key.
2. Enter the key using the **Set Gemini Key** option in NeuroPrep AI.
3. The key is used by the application for AI-powered functionality.

> **Never share your Gemini API key publicly or commit it to GitHub.**

For a production version, a secure backend/serverless architecture
would be recommended instead of exposing API credentials in a
client-side application.
